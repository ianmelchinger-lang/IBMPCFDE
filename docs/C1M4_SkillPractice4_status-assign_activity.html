What does the register say about each request?

When a request is missing from the register, one stakeholder reads the silence as a commitment and another reads it as an exclusion. A written status removes the guess. Each status also carries a duty, and a status with no authority behind it is still a guess.

Committed
The register will deliver it. It needs an acceptance method.
Excluded
Outside the boundary, for a reason, and it stays outside. Exclusion draws a boundary.
Deferred
Wanted, but not now. It needs a revisit trigger, the event that brings it back for a decision. Deferral says when to reconsider.
Assumed
The plan relies on it, and nobody has confirmed it. It needs a confirming party.
Unresolved
Nobody has accepted responsibility. It needs an owner and the decision it blocks.
